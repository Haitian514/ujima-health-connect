## Live demonstration

Open [MedConnect](https://medconnectnc.vercel.app). In Find care, submit a Durham search before selecting Primary care. Open Charlamy Megan Jones, review the published practice details, inspect the location in Map, save the provider, and add a personal follow-up note. Finish by showing the provider and note in My care. Personal notes do not book appointments; exact coverage, fees, availability, and transportation require confirmation with the relevant service.

These materials document a student prototype and do not establish clinical outcomes or completed user interviews. The short video is a backup preview; demonstrate the full task live when presenting.
